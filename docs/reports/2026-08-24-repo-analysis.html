Phân tích từng phân hệ

Auth — gpt/auth/

  • Login flow: CloakBrowser persistent context chống fingerprint; điền email/password/TOTP với typing delay giả lập người; phát hiện CAPTCHA chỉ đọc, không bao giờ bypass; phân cấp lỗi typed.
  • accounts.py (392 dòng, mới): registry JSON metadata-only, atomic write, chmod 0600/0700, validate tên chống path traversal; credentials lưu file riêng dạng pipe-delimited plaintext.
  • TOTP nhận cả seed base32 lẫn mã 6-digit dùng ngay. Tài liệu guide khớp code.

Transport — gpt/transport/

  • State machine với nhánh lỗi typed (AUTH_REQUIRED, RATE_LIMITED, COMMIT_UNKNOWN, PROTOCOL_CHANGED…). Điểm hay nhất: exception sau khi submit → CommitUnknown thay vì retry mù; reconcile() đọc history authoritative của web để xác nhận persist.
  • Hybrid: 1 page browser lấy token chung → pool curl_cffi (TLS impersonate Chrome, SSE stream). HTTP path luôn raise CommitUnknown khi reconcile — tránh resend trùng.
  • Multi-account (74 dòng): round-robin lease qua asyncio.Lock, pin account theo tên. Chưa có rate-limit per-account hay failover tự động.
  • Không retry/backoff tự động ở tầng nào — triết lý phân loại lỗi trước khi resend. Thread-safety asyncio đúng đắn.

Orchestrator — gpt/orchestrator/

  • Session runner: spawn claude -p … --dangerously-skip-permissions trỏ vào gateway local, timeout 300s; vòng 5 attempt xoay chiến thuật (TRIAGE → ERROR_FEEDBACK → ALTERNATIVE_VECTOR → CLEAN_REBOOT → EXTREME_REASONING); thất bại → NEEDS_HUMAN_REVIEW.md.
  • Race solver (191 dòng): tối đa 8 worker đua nhau — timing oracle Z-score/IQR, async fuzzing 100 req/s, differential, auth-bypass, PRNG cryptanalysis, AST RE, exploit synthesis — context cách ly qua scratch dir riêng; winner đầu tiên set stop-event.
  • gather(return_exceptions=True) nuốt exception worker crash; polling instance có thể chạy vô hạn không deadline.

Gateway — gpt/gateway/

  • Endpoints: health/readyz/models + /v1/chat/completions, /v1/responses, /v1/messages (+count_tokens), mỗi route có cả bản có/không tiền tố.
  • Runtime (1114 dòng): render prompt (compact tại 200K chars) → mark_pending → lease session → send 120s → parse tool calls → correction loop tối đa 2 lượt (TOOL_REFUSAL, MULTI_TOOL, INCOMPLETE_FANOUT, FALSE_COMPLETION…) → commit/reconcile. Trace middleware ghi metrics mọi request.
  • Không có auth HTTP/API key nào ở bất kỳ route nào.

Core utils

  • conversations.py: fingerprint SHA-256 canonical, prefix-matching request↔conversation web, persistence atomic + flock + TTL + LRU evict, fail-open có chủ ý. Chất lượng cao.
  • toolcall.py (864 dòng): transpiler 3 định dạng đầu vào → OpenAI function calls; fail-closed nghiêm ngặt; mask markdown trước khi dò sentinel; virtual Write tool với 2 lớp validation workspace-escape, atomic write, syntax-check. Fragile point: parser regex thay vì XML parser thật.
  • debug.py: CLI monolith hơi dài; credential xử lý cẩn thận (redact mọi JSON output, không log secret).

Solver scripts — solve_fast.py vs solve_v2_fast.py

  • Cả hai khôi phục token 48 ký tự bằng timing side-channel trên /api/authenticate.
  • v1: single-stage, control anchor '!'×48; bỏ sample lỗi (baseline lệch khi mạng xấu).
  • v2: two-stage adaptive (sweep nhanh → top-K → đo sâu), connection pool tùy chỉnh, lock sync URL, auto reset checkpoint khi container đổi; nhưng retry vô hạn có nguy cơ treo khi target chết.
  • Trùng lặp nặng giữa hai bản; cả hai hardcode URL instance CTF vào source.

Điểm mạnh & khuyến nghị

Điểm mạnh nổi bật

  • Fail-closed nhất quán: mọi trạng thái mơ hồ đều chặn thay vì đoán.
  • Pending/reconcile durability: two-phase commit cho turn gửi lên web — hiếm thấy ở project cùng loại.
  • Error taxonomy typed: 16 kiểu exception → status/retryable + header x-should-retry.
  • Secret hygiene runtime tốt: không log password/TOTP/token; debug dump chmod 0600 + redaction.
  • Evidence-gated replay + test discipline tốt (dual-backend asyncio+trio).

Khuyến nghị ưu tiên

  • Thêm API-key middleware + rate limit cho gateway; cảnh báo khi bind ngoài loopback.
  • Chạy orchestrator trong container/sandbox riêng; bỏ auto-trust workspace.
  • Mã hóa .cred qua keyring hoặc age/GPG; cân nhắc chuyển profile root khỏi ~/Downloads.
  • Hợp nhất gateway/server.py với api/server.py, chuyển test sang bản mới.
  • Deadline tổng cho ensure_instance_live; retry cap cho measure_token v2.
  • Dọn shim modules, tách solver script ra thư mục riêng, thêm CI chạy pytest.
